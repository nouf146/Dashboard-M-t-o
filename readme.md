# 🌤️ Dashboard Météo

## objectif du projet

Cette application permet d’ajouter des villes et afficher la météo actuelle grâce à l’API OpenWeatherMap.

L’utilisateur peut aussi supprimer des villes, modifier l’ordre des cartes et sauvegarder les données avec sessionStorage.

---

## Fonctionnalités

- Ajouter une ville
- Afficher la température actuelle
- Afficher la condition météo
- Supprimer une carte météo
- Monter et descendre les cartes
- Sauvegarder les données après actualisation de la page

---
